01

The problem behind the product

Operational information gets scattered across tasks, contacts, notes and technical references. The goal is to gather what needs attention and connect every decision to its context without creating extra work just to feed the system.

DAILY WORK

Less information in your head

A place to capture demands and organize priorities while keeping Personal and Work contexts separate.

EXECUTION

Visible deployments

Records, stages and a cockpit make implementation work easier to follow and prioritize.

CONTEXT

Understandable infrastructure

Rooms, equipment and technical points can be explored in the plan and in the store scene.

03

Store 360

The spatial layer of ProjectOps: connecting the store record to the infrastructure inside it. V1 combines a 2D plan, 3D visualization, point map and revisions in the same experience.

Implemented

2D plan

Equipment-family symbols, legend and selection to locate points and understand distribution.

Implemented

3D visualization

Environments, equipment silhouettes, automatic walls, floors and furniture for spatial reading.

Implemented

Shared context

Isolation, hiding and legend filters keep element visibility synchronized across plan and scene.

Implemented

Technical inspector

Code, category, room, position, dimensions and state for the selected element.

Implemented

Spatial orientation

Navigation cube, views, plan north and framing support store exploration.

Implemented

Reviews and demos

Store revisions and synthetic demo scenarios allow validation without exposing real operations.

04

Engineering behind the experience

Typed frontend

React 19, strict TypeScript, Vite, Tailwind CSS 4, shadcn/ui, TanStack Query and React Router.

Database authorization

Supabase Auth and PostgreSQL with RLS, relational integrity, versioned migrations and append-only auditing.

Layered verification

Typecheck, lint, domain/component tests, build checks, pgTAP and visual references for Store 360.

Clear product boundaries

ProjectOps evolves independently. N2 Control, Technician Dispatch and IT Inventory are separate projects.
